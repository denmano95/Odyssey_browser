DESCRIPTION
-----------
This is a Python-based program designed to 
process HTML data. 

The software allows users to make HTTP requests and view 
the processed output directly in the terminal.

REQUIREMENTS
------------
- Python 3.10.10
- Dependencies: PyQt6 , PyQt6-WebEngine


INSTALLATION & USAGE
--------------------
1. Ensure Python 3.10.10 is installed on your system.
2. Download the script files.
3. Run the program via terminal using or by using .exe file:
   
   python browser.py

   browser.exe
